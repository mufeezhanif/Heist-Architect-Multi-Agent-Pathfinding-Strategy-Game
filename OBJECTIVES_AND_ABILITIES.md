# 🎯 OBJECTIVES & ABILITIES GUIDE

---

## 📋 THE 4 OBJECTIVES (MISSIONS)

Each mission has a **specific location** on the maze marked with a **green octahedron symbol** (🎯).

### **OBJECTIVE 1: HACK THE SERVER** 💻
- **Location:** Hidden in a secure room
- **Completed by:** HACKER only
- **How to complete:** 
  1. Hacker reaches the green objective cell
  2. Uses the **DISABLE_DEVICE** ability (1 use consumed)
  3. The objective is marked as COMPLETE
- **Reward:** +50 score points
- **What it does in story:** Disables automatic alarms so guards are slower to respond

---

### **OBJECTIVE 2: STEAL THE LOOT** 💰
- **Location:** High-security vault room  
- **Completed by:** THIEF only
- **How to complete:**
  1. Thief reaches the green objective cell
  2. Just by being there, the loot is stolen (no ability needed!)
  3. Objective is COMPLETE
- **Reward:** +50 score points
- **What it does in story:** Get the valuable item - this is your main prize!

---

### **OBJECTIVE 3: DISABLE THE ALARM** 🚨
- **Location:** Control room with alarm panel
- **Completed by:** HACKER only
- **How to complete:**
  1. Hacker reaches the green objective cell
  2. Uses the **DISABLE_DEVICE** ability (1 use consumed)
  3. Objective is COMPLETE
- **Reward:** +50 score points
- **What it does in story:** Stops the building from going into full lockdown

---

### **OBJECTIVE 4: DISABLE THE CAMERA** 📷
- **Location:** Camera control hub
- **Completed by:** HACKER only
- **How to complete:**
  1. Hacker reaches the green objective cell
  2. Uses the **DISABLE_DEVICE** ability (1 use consumed)
  3. Objective is COMPLETE
- **Reward:** +50 score points
- **What it does in story:** Blinds guard surveillance systems

## ⚠️ IMPORTANT: NOT ALL BY THIEF!

**NO!** Objectives are NOT completed by the thief alone. Here's the breakdown:

| Objective | Agent | Ability Required |
|-----------|-------|------------------|
| Hack Server | HACKER | DISABLE_DEVICE |
| Steal Loot | THIEF | (None - just be there!) |
| Disable Alarm | HACKER | DISABLE_DEVICE |
| Disable Camera | HACKER | DISABLE_DEVICE |

**In plain words:**
- **HACKER does 3 objectives** (Hack, Alarm, Camera)
- **THIEF does 1 objective** (Loot - the easiest!)
- **MUSCLE does 0 objectives** (but helps escape!)

## 🎮 EACH AGENT'S UNIQUE POWERS

### **🟢 HACKER** (Green Border)

**Role:** Tech specialist who disables security systems

**Power 1: DISABLE DEVICE** 🔌
- **Uses:** 3 times per mission
- **Cooldown:** 2 turns between uses
- **What it does:** 
  - Hacks and disables cameras
  - Disables alarm systems
  - Disables security devices
  - Solves 3 out of 4 objectives
- **Strategy:** Use wisely! You only have 3 uses for 3 objectives
- **Best for:** Going invisible (disabling cameras before passing)

**Stats:**
- Speed: 2 tiles per turn
- Health: 3 hits before captured
- Weakness: Weak in combat (use DISABLE_DEVICE to avoid guards)
- Strength: Can neutralize security instead of fighting

---

### **🔴 THIEF** (Red/Pink Border)

**Role:** Agile specialist who moves fast and picks locks

**Power 1: PICK LOCK** 🔑
- **Uses:** 3 times per mission
- **Cooldown:** 2 turns between uses
- **What it does:**
  - Opens locked doors without triggering sensors
  - Creates shortcuts through the building
  - Bypasses security gates
- **Strategy:** Use to find alternate routes avoiding guards
- **Best for:** Sneaky passages and escape routes

**Power 2: SPRINT** 🚀
- **Uses:** 3 times per mission
- **Cooldown:** 2 turns between uses
- **What it does:**
  - Move 2 extra tiles in ONE turn
  - Perfect for quick escapes
  - Dodge incoming guards
- **Strategy:** Use when a guard is close to catch you
- **Best for:** Last-second escapes and speed runs

**Stats:**
- Speed: 2 tiles per turn (3 with SPRINT active)
- Health: 3 hits before captured
- Weakness: Weakest in direct combat
- Strength: FASTEST agent + can pick any lock

**Special:** Thief is the ONLY one who can steal the loot!

---

### **🟡 MUSCLE** (Yellow Border)

**Role:** Strong fighter who can knock out guards

**Power 1: KNOCK OUT** 💥
- **Uses:** 3 times per mission
- **Cooldown:** 2 turns between uses
- **What it does:**
  - Neutralizes 1 guard (removes them from patrol)
  - Guard is knocked out temporarily
  - Clears a path without stealth
- **Strategy:** Use on guards blocking escape routes
- **Best for:** Direct approach - knock guards and walk past
- **WARNING:** Alertness increased when used!

**Special Ability: Built for Combat**
- Highest damage output
- Can survive more hits than others
- Intimidating presence (guards fear Muscle)

**Stats:**
- Speed: 2 tiles per turn (same as others)
- Health: 3 hits before captured
- Strength: Strongest in direct combat
- Weakness: Loud - more likely to trigger alarms when fighting

## ⚡ ABILITY COOLDOWN EXPLANATION

**What is "Cooldown"?**
- After using an ability, you must wait 2 turns before using it again
- This prevents spamming the same ability repeatedly

**Example:**
```
Turn 1: Hacker uses DISABLE_DEVICE → Camera disabled
Turn 2: COOLDOWN (can't use)
Turn 3: COOLDOWN (can't use)
Turn 4: Can use DISABLE_DEVICE again
```

## 🚨 ALERT LEVELS & CONSEQUENCES

Each time you use an offensive ability (KNOCK_OUT, SPRINT near guards), alert level rises:

| Level | Status | What Happens |
|-------|--------|--------------|
| 🟢 GREEN | Safe | Proceed normally |
| 🟡 YELLOW | Caution | Guards search harder |
| 🔴 RED | Danger | Guards actively hunt |
| ⚫ LOCKDOWN | GAME OVER | Building sealed - you lose |

**Pro Tip:** Use abilities strategically to keep alerts LOW!

## ❓ FAQ

**Q: Can Muscle steal the loot?**
A: No, only Thief can. Muscle is too intimidating and sets off alarms!

**Q: Can Hacker knock out guards?**
A: No, only Muscle has KNOCK_OUT. Hacker disables tech instead.

**Q: What if I use all 3 DISABLE_DEVICE uses on cameras?**
A: You'll fail! You need them for Server AND Alarm. Plan wisely!

**Q: Can Thief hack the server?**
A: No, that's Hacker's expertise. Thief focuses on locks and speed.

**Q: Do I have to use all abilities?**
A: No! Only use what you need. Extra uses = higher score.

**Q: What if Hacker dies before hacking the server?**
A: You cannot complete that objective - GAME OVER!

**Q: Can I use SPRINT while carrying loot?**
A: Yes! Thief sprints WITH the loot to escape faster.

**Q: Does KNOCK_OUT kill guards forever?**
A: No, they wake up after a while. Use it to clear paths, not permanently.
